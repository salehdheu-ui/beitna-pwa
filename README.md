# 🏡 بيتنا — نسخة الويب

### 🔗 التطبيق المباشر: **https://beitna.saher.cloud**

**إدارة المنزل بذكاء** — نسخة ويب كاملة من تطبيق «بيتنا» للأندرويد، مبنية كـ

`PWA`

أي تطبيق ويب قابل للتثبيت على الجوال وسطح المكتب ويعمل بدون إنترنت.

---

## ✨ المزايا

| القسم | الوصف |
|---|---|
| 🏠 **الرئيسية** | ملخص اليوم، الأولويات العاجلة، إجراءات سريعة، آخر النشاطات، إحصائيات فعلية |
| 🛒 **المشتريات** | إضافة عناصر بكمية وتصنيف وأولوية وسعر، فلاتر، بحث، شريط تقدّم، جلسة تسوّق، قوائم مفضلة، مشاركة القائمة |
| 🔧 **الأعطال** | تسجيل الأعطال بالمكان والأولوية، إرفاق صورة، جدولة إصلاح مع اسم الفني، تكلفة تقديرية وفعلية |
| 🎉 **المناسبات** | تقويم شهري، تبويبات (القادمة / اليوم / هذا الأسبوع / المتكررة)، تذكيرات متعددة، تجديد سنوي تلقائي |
| 👨‍👩‍👧 **أفراد البيت** | كود دعوة قابل للنسخ والمشاركة، إدارة الأعضاء وأدوارهم |
| ⚙️ **المزيد** | الملف الشخصي، الإشعارات، التصنيفات والأماكن، الأرشيف، الوضع الليلي، الدعم، نسخة احتياطية |

### مزايا تقنية

- **مزامنة بين كل أفراد البيت** عبر خادم مستضاف ذاتيًا على خادمك أنت — بدون أي طرف خارجي
- **إشعارات نشاط الشريك** — ينبّهك فورًا عند إضافة أي فرد لعنصر أو عطل أو مناسبة
- **وضع محلي اختياري** بدون حساب لمن يريد جهازًا واحدًا فقط
- يعمل **بدون إنترنت** بالكامل عبر
  `Service Worker`
- **قابل للتثبيت** على شاشة الجوال الرئيسية كتطبيق مستقل
- **تذكيرات** للمناسبات والعناصر الضرورية
- **الوضع الليلي** الكامل
- تصميم **عربي أصيل** من اليمين لليسار، متجاوب من الجوال حتى سطح المكتب
- **نسخ احتياطي واستيراد** بصيغة
  `JSON`

## 🚀 التشغيل محليًا

```bash
git clone https://github.com/salehdheu-ui/beitna-pwa.git
cd beitna-pwa
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

> لا يوجد أي خطوة بناء ولا حزم خارجية — ملفات ثابتة فقط.

## 🌍 النشر

الموقع منشور ومباشر على الخادم الخاص عبر
`Coolify`
كموقع ثابت خلف
`nginx`
:

**https://beitna.saher.cloud**

المشروع يُنشر كخدمتين على نفس الدومين:

**1) الموقع (ملفات ثابتة)**

1. `Add Resource` ثم `Public Repository`
2. رابط المستودع، والفرع `main`
3. `Build Pack` = `Static`، و `Base Directory` = `/`
4. الدومين: `https://beitna.saher.cloud` (الشهادة تلقائية عبر `Let's Encrypt`)

**2) الخادم (الحسابات والمزامنة)**

1. `Add Resource` ثم `Public Repository`
2. نفس المستودع والفرع
3. `Build Pack` = `Dockerfile`، و `Base Directory` = `/server`
4. الدومين: `https://beitna.saher.cloud/api`
5. `Persistent Storage` → مجلد دائم على المسار `/data` (هنا تُحفظ كل البيانات)

لا يحتاج الخادم أي متغيّر بيئة ولا أي مفتاح: مفتاح توقيع الجلسات يُولَّد ذاتيًا
عند أول تشغيل ويُحفظ في المجلد الدائم.

### ⚠️ نوع ملف الـ manifest على nginx

`nginx` لا يعرف الامتداد `.webmanifest` افتراضيًا فيقدّمه بنوع
`application/octet-stream`، وهذا يربك متصفحات الجوال.
لذلك `index.html` يشير إلى **`manifest.json`** (يصل بنوع `application/json` من أي خادم).

وإن رغبت باستخدام `.webmanifest` مستقبلًا، أضف في إعداد `nginx`:

```nginx
types { application/manifest+json webmanifest; }
```

## 🔔 الإشعارات والتثبيت — ما الذي يعمل وأين

| | أندرويد (Chrome) | iPhone (Safari) |
|---|---|---|
| التثبيت | زر «تثبيت» يظهر تلقائيًا | يدويًا: مشاركة ← «إضافة إلى الشاشة الرئيسية» (التطبيق يعرض الخطوات) |
| الإشعارات | تعمل من المتصفح ومن التطبيق المثبّت | **تعمل فقط بعد التثبيت** على الشاشة الرئيسية (iOS 16.4 فأحدث) |

كل الإشعارات تمر عبر `ServiceWorkerRegistration.showNotification()`؛
الشكل القديم `new Notification()` **لا يعمل على الجوال إطلاقًا**
(أندرويد يرميه كخطأ، و iPhone لا يعرّفه أصلًا).

التذكيرات تُحسب على الجهاز نفسه، فتصل ما دام التطبيق مفتوحًا أو يعمل في الخلفية.
لإرسال تذكيرات والتطبيق مغلق تمامًا يلزم `Web Push` بمفاتيح `VAPID` من الخادم —
مستقبِل الرسائل جاهز في `sw.js` (حدث `push`) وينقص طرف الخادم فقط.

## 🗂️ بنية المشروع

```
beitna-pwa/
├── index.html               # الهيكل الأساسي
├── manifest.json            # بيانات التطبيق للتثبيت (المرتبط في index.html)
├── manifest.webmanifest     # نسخة مطابقة للتوافق مع الروابط القديمة
├── sw.js                    # العمل بدون إنترنت
├── server/                  # الخادم الذاتي (حسابات + مزامنة)
├── css/app.css              # نظام التصميم الكامل
├── js/
│   ├── app.js               # نقطة البداية والتنقل
│   ├── cloud.js             # الاتصال بالخادم — الحساب والمزامنة وطابور العمل بدون إنترنت
│   ├── router.js            # الموجّه
│   ├── store.js             # طبقة البيانات والتخزين
│   ├── ui.js                # نوافذ وتنبيهات وعناصر مشتركة
│   ├── util.js              # أدوات التاريخ والنصوص
│   ├── notify.js            # التذكيرات والإشعارات
│   └── screens/             # الشاشات (رئيسية، مشتريات، أعطال، مناسبات، المزيد)
└── assets/icons/            # أيقونات التطبيق
```

## ☁️ المزامنة بين الأجهزة

كل شيء يعمل على خادم واحد صغير تملكه أنت، داخل مجلد
`server/`
ويُنشر مع الموقع نفسه على المسار
`/api`
— بدون أي اعتماد على خدمة خارجية، وبدون أي مكتبات خارجية.

البيانات تُحفظ في مجلد دائم على الخادم
`/data`
ولا تُفقد عند إعادة النشر:

```
users/{uid}                     → displayName, email, householdId
households/{hid}                → name, inviteCode, createdBy
households/{hid}/members/{uid}  → name, role, isOwner, joinedAt
households/{hid}/shopping/{id}  → المشتريات
households/{hid}/faults/{id}    → الأعطال
households/{hid}/occasions/{id} → المناسبات
households/{hid}/categories/{id}→ التصنيفات
```

### الحسابات والأمان

- كلمات المرور محفوظة بخوارزمية
  `scrypt`
  مع مِلح عشوائي لكل حساب — لا تُخزَّن أبدًا كما هي
- الجلسات برموز موقّعة بـ
  `HMAC-SHA256`
  ومفتاح التوقيع يُولَّد ذاتيًا على الخادم عند أول تشغيل
- كل بيت معزول تمامًا: من ليس عضوًا فيه لا يستطيع قراءة بياناته ولا الكتابة فيها
- حماية من المحاولات المتكررة على تسجيل الدخول

### العمل بدون إنترنت

- التطبيق يفتح من آخر نسخة محفوظة على الجهاز خلال أقل من نصف ثانية، بدون انتظار أي شبكة
- كل إضافة أو تعديل أو حذف يُطبَّق محليًا فورًا ويدخل طابور انتظار
- أول ما يعود الاتصال يُرفع الطابور تلقائيًا ويلحق التطبيق بآخر تحديث
- التعديل المحلي الأحدث يفوز دائمًا، فلا يُلغى عملك بنسخة قديمة من الخادم

**الوضعان معًا:**

| | مع حساب | بدون حساب |
|---|---|---|
| المزامنة بين الأجهزة | ✅ | ❌ |
| إشعار نشاط الشريك | ✅ | ❌ |
| العمل بدون إنترنت | ✅ | ✅ |
| يحتاج تسجيل دخول | نعم | لا |
