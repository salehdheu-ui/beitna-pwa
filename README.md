# 🏡 بيتنا — نسخة الويب

**إدارة المنزل بذكاء** — نسخة ويب كاملة من تطبيق «بيتنا» للأندرويد، مبنية كـ

`PWA`

أي تطبيق ويب قابل للتثبيت على الجوال وسطح المكتب ويعمل بدون إنترنت.

---

## ✨ المزايا

| القسم | الوصف |
|---|---|
| 🏠 **الرئيسية** | ملخص اليوم، الأولويات العاجلة، إجراءات سريعة، آخر النشاطات، إحصائيات فعلية |
| 🛒 **المشتريات** | إضافة عناصر بكمية وتصنيف وأولوية وسعر، فلاتر، بحث، شريط تقدّم، جلسة تسوّق، قوائم مفضلة، مشاركة القائمة |
| 🔧 **الأعطال** | تسجيل الأعطال بالمكان والأولوية، إرفاق صورة، جدولة إصلاح مع اسم الفني، تكلفة تقديرية وفعلية |
| 🎉 **المناسبات** | تقويم شهري، تبويبات (القادمة / اليوم / هذا الأسبوع / المتكررة)، تذكيرات متعددة، تجديد سنوي تلقائي |
| 👨‍👩‍👧 **أفراد البيت** | كود دعوة قابل للنسخ والمشاركة، إدارة الأعضاء وأدوارهم |
| ⚙️ **المزيد** | الملف الشخصي، الإشعارات، التصنيفات والأماكن، الأرشيف، الوضع الليلي، الدعم، نسخة احتياطية |

### مزايا تقنية

- يعمل **بدون إنترنت** بالكامل عبر
  `Service Worker`
- **قابل للتثبيت** على شاشة الجوال الرئيسية كتطبيق مستقل
- **إشعارات وتذكيرات** للمناسبات والعناصر الضرورية
- **الوضع الليلي** الكامل
- تصميم **عربي أصيل** من اليمين لليسار، متجاوب من الجوال حتى سطح المكتب
- **نسخ احتياطي واستيراد** بصيغة
  `JSON`
- **بدون أي خادم** — البيانات محفوظة داخل جهازك فقط

## 🚀 التشغيل محليًا

```bash
git clone https://github.com/salehdheu-ui/beitna-pwa.git
cd beitna-pwa
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

> لا يوجد أي خطوة بناء ولا حزم خارجية — ملفات ثابتة فقط.

## 🌍 النشر

الموقع منشور على
`Netlify`
ويُحدَّث تلقائيًا مع كل تحديث في هذا المستودع.

للنشر بنفسك:

1. ادخل على
   `app.netlify.com`
2. اختر
   `Add new site → Import an existing project`
3. اربط المستودع، واترك خانة أمر البناء فارغة، واجعل مجلد النشر هو
   `.`

يعمل أيضًا مباشرة على
`GitHub Pages`
أو
`Vercel`
أو
`Cloudflare Pages`
بدون أي تعديل.


## 🔄 الفرق عن نسخة الأندرويد

نسخة الأندرويد كانت تحفظ البيانات في
`Firebase Firestore`
لمزامنة أفراد البيت لحظيًا.

نسخة الويب هنا **محلية بالكامل**: البيانات تُحفظ داخل متصفح الجهاز، فتعمل بدون إنترنت ودون حساب ودون أي تكاليف تشغيل. لنقل بياناتك بين جهازين استخدم **تصدير نسخة احتياطية** ثم **استيراد نسخة** من شاشة «المزيد».

بنية البيانات هنا مطابقة لبنية النسخة الأصلية، فيمكن لاحقًا ربطها بأي خدمة سحابية دون إعادة كتابة الشاشات.
